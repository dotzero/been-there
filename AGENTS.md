# Repository Guidelines

## Project Structure & Module Organization

This is a Vite + React single-page app for rendering and sharing a visited-countries map.

- `src/main.jsx` contains the React app, map rendering, URL state, export logic, and Mapbox setup.
- `src/countries.js` stores country metadata used by the selector and map matching.
- `src/styles.css` contains all application styling.
- `public/` contains static assets copied into the Vite build.
- `etc/nginx.conf` and `etc/docker-entrypoint.d/` support the production nginx container.
- `dist/` is generated by `npm run build`; do not edit it by hand.

## Build, Test, and Development Commands

- `npm install` installs dependencies for local development.
- `npm run dev` starts Vite on `0.0.0.0`; open `http://localhost:5173/`.
- `npm run lint` runs ESLint across the repository.
- `npm run build` creates the production bundle in `dist/`.
- `npm run preview` serves the built app locally.
- `MAPBOX_TOKEN=pk... docker compose up` runs the nginx container with a runtime Mapbox token.

## Coding Style & Naming Conventions

Use modern ES modules and React function components. Prefer `const` unless reassignment is required. Keep constants in `SCREAMING_SNAKE_CASE`, components in `PascalCase`, and regular functions/variables in `camelCase`.

Follow the existing style: two-space indentation, semicolons, single quotes in JavaScript, and concise CSS class names such as `.country--visited`.

## Testing Guidelines

There is currently no automated test runner. Treat `npm run lint` and `npm run build` as required checks. For UI changes, manually verify Mapbox mode and SVG fallback mode, including country selection, share URLs, language/style switching, and PNG export.

When adding tests, place them near the covered code or in a clearly named test directory, and document the new command in `package.json`.

## Commit & Pull Request Guidelines

Recent commits use short imperative messages, for example `Fix fallback map` and `Pass MAPBOX_TOKEN via runtime`. Keep subjects focused on behavior.

Pull requests should include a brief summary, screenshots or recordings for visual changes, and verification commands. Link related issues when available. Mention configuration changes explicitly, especially around `MAPBOX_TOKEN`, Docker, nginx, or URL serialization.

## Security & Configuration Tips

`MAPBOX_TOKEN` is a public browser token, but restrict it by allowed URLs in Mapbox before publishing. Do not commit real `.env` values. In Docker, the token is injected at startup by patching `index.html`; keep `index.html` uncached in nginx so token changes take effect after restarts.
